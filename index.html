A. Array Sum
EASY 1.0s / 256MB

Problem Statement

Given an array of $N$ integers and $Q$ queries, for each query calculate the sum of numbers between indices $L$ and $R$ (1-indexed). Return the computed sum for each query on a new line.

Input Format

First line contains integer N (size of array). Second line contains N integers. Third line contains Q. Following Q lines contain pairs L and R.

Output Format

Print the range sum for each query on a separate line.
